# 煉金畫廊

用 Three.js 做的 3D 線上畫廊。手機為主，電腦也能看。不需要編譯，改完檔案就能上傳。

第三人稱視角，操控一個小煉金學徒在雜亂的工作室裡逛。

手機：

- 右下搖桿：走路，推越遠走越快。
- 左下「跳」：跳躍。旁邊的「坐」：原地坐在地上，附近有椅子就坐椅子；坐著時變成「起」。
- 點地面：自動走過去，會繞開家具。
- 靠近畫作時搖桿上方出現「看畫」：按下去走到畫前，鏡頭轉到正面，跳出作品資訊。直接點畫也可以。
- 前廳入口那面牆有一面穿衣鏡，靠近時出現「照鏡子」，可以換長袍、帽子、圍巾的顏色。
- 戶外的長椅、椅子、野餐墊旁邊出現「坐下」。坐下時鏡頭不會變，坐著也能照常轉鏡頭。坐在陽台長桌邊可以「拿點心」，拿著點心時按「吃一口」，三口吃完。推搖桿、點地面或按「起」就會站起來。
- 靠近動物時出現「摸摸」，按下去走到牠面前摸一摸。直接點動物也可以。
- 看畫時左右滑：換到上一幅或下一幅。上下拖曳就回到走路。
- 拖曳畫面：繞著角色轉鏡頭。往上拖到鏡頭貼近地面後繼續拖，會變成抬頭往上看，一直看到天頂。雙指：拉近拉遠。
- 右上角「回正」：鏡頭轉回角色背後。

電腦：

- WASD 或方向鍵走路，Q / E 轉鏡頭，R 回正，空白鍵跳躍，C 坐下或站起來，Enter 看畫、照鏡子、坐下、拿點心、摸動物。
- 滑鼠點地面走路、拖曳轉鏡頭、滾輪縮放。

擋在鏡頭和角色之間的牆會自動降成矮牆，靠牆的高家具會變半透明。

## 在自己電腦上預覽

雙擊 `開啟畫廊.bat`，瀏覽器會自動打開 `http://localhost:8000`。看完把黑色視窗關掉即可。

直接雙擊 `index.html` 是打不開的，瀏覽器不允許網頁從硬碟讀設定檔，一定要透過這個小伺服器。

手機要在同一個 Wi-Fi 下測試的話，把網址裡的 `localhost` 換成電腦的區網 IP（例如 `http://192.168.1.23:8000`）。

## 資料夾

```
gallery.json          房間順序、洽詢連結
rooms/
  01-vestibule/       一個資料夾就是一間房
    room.json         房名、房型、牆上的畫
    paintings/        這間房的圖檔
  02-nigredo/
  03-rubedo/
js/  css/  vendor/    程式，平常不用動
```

## 換成自己的畫

1. 把圖檔放進該房間的 `paintings/` 資料夾。
2. 打開 `room.json`，修改那幅畫的欄位。

```json
{
  "title": "作品名稱",
  "year": 2025,
  "medium": "油彩、畫布",
  "width": 60,
  "height": 80,
  "price": 38000,
  "status": "available",
  "image": "paintings/my-painting.jpg",
  "thumb": "paintings/my-painting-small.jpg",
  "buyUrl": "",
  "note": "作品說明，可以留空。"
}
```

| 欄位 | 說明 |
|---|---|
| `width` `height` | 實際尺寸，單位公分。畫框在牆上的大小依這個比例 |
| `price` | 新台幣，只填數字 |
| `status` | `available` 可購買、`reserved` 已預訂、`sold` 已售出 |
| `image` | 點開作品時顯示的大圖。建議 JPG，長邊 2000px 左右 |
| `thumb` | 掛在 3D 牆上的小圖，長邊 1024px 就夠。可以不填，不填就用大圖，但手機會比較吃力 |
| `buyUrl` | 購買連結。沒填的話，按鈕會變成「洽詢」並連到 `gallery.json` 的 `contact` |
| `note` | 作品說明 |
| `frame` | 選填。畫框樣式 0 胡桃木、1 金色、2 黑色、3 橡木。不填會輪流使用 |

已售出的畫不顯示價格。

## 新增房間

1. 複製一個現有的房間資料夾，改名，例如 `04-albedo`。資料夾名稱請用英文、數字和減號。
2. 修改裡面的 `room.json`：房名、房型、畫作。
3. 打開 `gallery.json`，把資料夾名稱加進 `order`。放第一個，就是新的入口；放最後，就接在最裡面。

```json
{ "order": ["04-albedo", "01-vestibule", "02-nigredo", "03-rubedo"] }
```

房間一律依 `order` 的順序一直線接下去，門會自動開好。

### 房型

| `type` | 樣子 | 可掛幅數 |
|---|---|---|
| `hall` | 8 × 8 公尺方廳 | 6，最後一間 7 |
| `corridor` | 5 × 12 公尺長廊 | 6，最後一間 7 |
| `rotunda` | 直徑 10 公尺圓廳 | 6，最後一間 7 |

最後一間的盡頭沒有門，會多出正中央一個位置。圓廳當最後一間時，第一幅畫會掛在正對入口的那面牆。開了戶外（見下一節）的話，最後一間的盡頭會開一扇後門，就沒有這個多出來的位置。

## 戶外：陽台和草原

`gallery.json` 的 `"outdoor": true` 會在最後一間房後面開一扇後門，接到陽台「宴」。陽台上有招待客人的長桌，桌頭站著另一隻海牛頭人。從石階走下去是草原「原野」，有一棵大樹、樹下的長椅和野餐墊，時間固定在黃昏。

- 一走出後門，光線和霧會慢慢換成戶外的黃昏，聽得到風聲、海浪和鳥叫。右上角的喇叭按鈕可以靜音，連動物的叫聲一起關掉。聲音是瀏覽器現場合成的，不用下載音檔；選擇會記在瀏覽器裡。
- 坐下（包括坐在地上）和手上拿的點心，其他訪客也看得到。
- 草原上有兩頭乳牛、四隻母雞、一群鴨子（白鴨媽媽帶三隻小鴨，加上一對綠頭鴨）和一隻小狗。黑化走廊裡住著一隻黑貓。

### 動物

每隻動物有自己的作息：乳牛吃草、反芻、趴下休息；母雞啄地、扒土、東張西望；小鴨排成一列跟著媽媽走；小狗到處聞、坐下、偶爾繞圈暴衝；黑貓大部分時間在睡覺，醒來會坐著理毛，換個角落再睡。

- 靠近按「摸摸」：乳牛把鼻子低下來湊過來，母雞蓬起羽毛，鴨子原地搖擺，小狗翻肚，黑貓坐起來用頭蹭你、呼嚕。
- 小狗看到你走下草原會跑過來，坐在旁邊，你走開牠會跟一段路。
- 在雞、鴨、貓旁邊跳起來會把牠們嚇跑，小狗會跟著跳。走路直直撞過去，牠們也會讓開。乳牛不會讓，要繞過去。
- 每隻動物會叫，越近越大聲。

動物去哪裡、做什麼，是用「第幾隻動物、現在是第幾段時間」算出來的，每位訪客看到的位置都一樣，不用另外傳資料。被摸的時候會同步給其他訪客；跑來打招呼、被嚇跑這些反應只在自己的畫面上演，演完再走回原本的行程。
- 不想要戶外，把 `outdoor` 改成 `false` 或刪掉即可。

### 家具主題

`room.json` 的 `props` 決定房間裡堆什麼東西：

| `props` | 內容 |
|---|---|
| `studio` | 畫室：畫架、靠牆的畫布、顏料桌、凳子、地上的顏料點和紙 |
| `library` | 書房：書櫃、扶手椅、立燈 |
| `lab` | 煉金實驗室：藥瓶櫃、燒瓶桌、煉金鍋 |

家具位置由程式自動排，會避開畫、門口和走道。同一間房每次打開都長一樣。不喜歡目前的擺法，可以在 `room.json` 加 `"seed": "2"`（任意文字），換一組排列。

其他選項：

- `"color": "#d9b98c"`：牆面顏色。
- 每間房都有地毯、燈串，條件允許時外牆會開一扇窗，房間中間偶爾會有一隻睡著的貓（黑貓住的那一間不放）。

## 購買連結

目前每幅畫各自連到外部結帳頁，網站本身不處理金流。台灣常見的做法：

- 綠界 ECPay、藍新 NewebPay 的「收款連結」，每幅畫建一個，貼進 `buyUrl`。
- 或在 Pinkoi、Shopline 開商品頁，貼商品網址。

原作只有一件，賣出後記得把 `status` 改成 `sold`。

`gallery.json` 的 `contact` 可以填 LINE 官方帳號連結，或 `mailto:你的信箱`。

## 多人同遊

同一時間來逛的人會看到彼此。每個人的學徒配色是自己在鏡子前選的，別人看到的也是同一套；第一次來的人會隨機配一套，存在瀏覽器裡，下次來還是同一套。不取名、不能打字聊天，只能送表情（❤️ ✨ 👏 😮 👋），角色會做對應的動作，表情在頭上飄一下。跳躍和摸動物別人也看得到。右上角顯示目前在線人數。電腦可以按數字鍵 1–5 送表情。

這個功能需要一個免費的 Supabase 專案負責轉發訊息。`gallery.json` 的 `realtime` 沒填就不會啟用，畫廊照常是單人模式。

設定步驟：

1. 到 supabase.com 註冊，建立一個新專案（Project），地區選 Northeast Asia (Tokyo) 或 Singapore，離台灣近。
2. 進專案後打開 Project Settings → API（或 API Keys），複製 Project URL 和公開金鑰（publishable key，舊專案叫 anon key）。
3. 填進 `gallery.json`：

```json
"realtime": {
  "url": "https://xxxxxxxx.supabase.co",
  "key": "sb_publishable_xxxxxxxx"
}
```

公開金鑰本來就是設計給網頁用的，放在網站上沒有關係。不要填 secret key 或 service_role key。

傳送的資料只有位置、面向、在哪一間房、配色、坐在哪個位子、手上拿什麼點心，以及「跳了」「送了哪個表情」「摸了哪隻動物」，不需要登入，也不存進資料庫。同一個房間最多畫出最近的 10 位訪客。Supabase 免費方案對同時連線數和每月訊息量有上限，小型畫廊一般用不完；超過時多人功能會暫時失效，畫廊本身不受影響。免費專案一段時間沒有人連線會被暫停，到 Supabase 後台按一下就能恢復。

## 平面模式

網址後面加 `?flat`，會直接顯示作品清單，不載入 3D。手機跑不動 3D 時也會自動切換。右上角的「清單」按鈕隨時可以打開同樣的列表。

## 效能上做了什麼

- 不計算即時陰影。家具和角色腳下的影子是預先畫好的半透明圓斑。
- 同一間房的所有家具合併成少數幾個網格，一間房大約 30 次繪製呼叫。
- 只載入目前房間前後各一間的畫作圖檔，離開兩間以上就釋放。
- 手機解析度上限 1.5 倍。
- 畫面靜止時降到約每秒 30 張。
- 牆、地板、地毯、家具、角色都是程式產生的，除了 Three.js 本身之外沒有要下載的模型或材質。

## 上線與更新

網址：https://bluedot2049.github.io

程式放在 GitHub 的 `bluedot2049/bluedot2049.github.io`。每次推送到 `main` 分支，GitHub Actions 會自動發佈（設定在 `.github/workflows/deploy.yml`）。

改完畫作或設定後，雙擊 `更新網站.bat`，它會把變更上傳，網站一兩分鐘後更新。建議先用 `開啟畫廊.bat` 在本機確認沒問題，再上傳。

原始高解析畫檔請放在 `originals/` 資料夾，這個資料夾不會被上傳。
